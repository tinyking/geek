这是一个刚刚诞生不久的开源 Markdown 知识库管理工具，专为"AI时代"设计，巧妙地融合了 Notion 的编辑体验和 Obsidian 的本地化数据理念。它由资深技术人 Luca 为自己打造，一经发布便因**完全本地化、原生Git集成、为AI协作而生**等理念，在开发者社区引发了大量讨论。

## 🚀 Tolaria 是什么？

Tolaria 的核心定位是 **"AI时代的第二大脑"**，一个开源、完全免费的 macOS 原生桌面应用。它的设计目标是将你所有笔记、文档整理成一个清晰、结构化、AI易于理解的 Markdown 知识库。

你可以把它看作是 **"本地版的 Notion"** 或 **"内置了 Git 和 AI 优化的 Obsidian"**。不过，它的侧重点和 Obsidian 有所不同，Tolaria 更偏向于知识管理体系的搭建和 AI 协作，而 Obsidian 则更偏向个人笔记和文档链接。

## ✨ 核心优势与功能

Tolaria 的价值体现在以下几个关键方面：

| 特性分类 | 具体功能点 | 用户价值 |
| :--- | :--- | :--- |
| **📝 数据主权** | 本地文件存储为 `.md` 文件，无黑盒数据库，可完全离线使用 | 用户对数据拥有绝对控制权，即便软件停止维护，知识库依然完好 |
| **📝 编辑体验** | 类 Notion 所见即所得编辑界面，支持斜杠命令、拖拽图片和 `[[wikilinks]]` 双链 | 既有现代化编辑的流畅体验，又保留了纯文本的灵活与纯粹 |
| **🔄 版本控制** | 原生 Git 集成，内置 Diff 视图，支持提交、推送、查看历史 | 提供了强大的安全保障，开发者可以轻松回溯任何历史版本 |
| **🤖 AI 协作** | 开放 MCP 服务器接口，支持 Claude Code 等 AI 工具直接读取、编辑笔记 | 知识库不仅能"看"，还能被 AI"理解"和"操作"，实现真正的协作 |
| **🎨 结构体系** | 属性系统 + 类型系统，支持丰富元数据定义和笔记模板 | 帮助用户搭建个人知识管理体系，由轻量级笔记工具转向系统化管理 |

## 💻 极客风范

许多用户对 Tolaria 的第一印象是**快、轻、独特**。它采用 **Tauri + React + TypeScript** 技术栈构建，应用包体只有惊人的 **23MB**。其界面设计追求极致速度和流畅度，在 M1 Mac 上滚动浏览包含 2500 个文件的笔记库时，能达到 **60fps** 的丝滑性能。

## 👨‍💻 背景与愿景

- **作者与背景**：Tolaria 由 **Luca Rossi** 开发，他是一名资深软件工程师，运营知名技术 Newsletter《Refactoring》多年，积累了大量忠实读者。
- **开发动力**：在 5 年创作了 300 多篇文章后，他发现自己用 Notion 管理的 **9000 多条笔记** 在数据检索和复用上遇到瓶颈。为了找到一个能让他与 **AI 高效协作** 的知识库，他决定自己动手。

## 🐾 如何开始

你可以直接从 [Tolaria 官网](https://tolaria.md/) 下载 macOS 应用。它也支持 Linux 系统，但目前暂无 Windows 版本。不过，根据作者在 HN 上的回复，Windows 版本的开发已在他的计划中。

## 🤔 当前局限

作为新项目，Tolaria 也存在一些明显的局限：

- **平台支持有限**：目前仅提供 macOS 和 Linux 版本，暂无 Windows 和移动端支持。
- **用户门槛较高**：核心功能如 Git 集成、Wikilinks 更适合熟悉 Git、Markdown 等技术概念的开发者或高级用户。
- **社区生态起步**：相比 Obsidian 庞大的插件社区，Tolaria 的生态系统刚刚起步，可定制性在短期内可能有所局限。

总的来说，Tolaria 准确地抓住了开发者群体对数据主权、版本控制以及 AI 协作的强烈需求，凭借"文件为先、Git集成、AI原生"的独特定位，在笔记工具的红海中开辟了一个全新的品类。如果你符合以下画像之一，它尤其值得尝试：

- **数据主权重视者**：希望完全掌控自己的数据，不想被任何平台锁定。
- **Git 爱好者**：习惯使用 Git 进行版本控制，享受 diff 视图带来的安全感。
- **AI 深度用户**：希望你的笔记知识库能与 Claude 等 AI 工具进行交互。
- **知识管理探索者**：对知识管理有较高要求，希望通过属性和类型系统构建自己的知识体系。

这款新工具的定位非常精准，强烈建议你去探索一下。
